## index.html 运作方式

`index.html` 是一个不依赖任何建置工具的单页应用程序（SPA），唯一的外部依赖是 [marked.js](https://github.com/markedjs/marked)（用于将 Markdown 转换为 HTML）。

**内核流程：**

1. **数据源**：启动时通过 `fetch` 加载 `README.md`，解析其中 `### 主题名称` 和 `- [链接](路徑) — 描述` 的结构，分别取得各主题与跨主题集成分析的数据
2. **首页呈现**：首页有四个页签 — 学习路线图、各主题分析（卡片式列表）、跨主题集成分析、术语总表。学习路线图和术语总表分别从 `src/学习路线图.md` 和 `src/术语总表.md` 加载后以 marked.js 渲染
3. **主题阅读器**：点击任一主题卡片后进入阅读器视图，通过页签切换该主题下的六份文档（专业版、白话版、案例分析、练习与自测、进一步学习、交互图表）。Markdown 文档以 `fetch` 加载并用 marked.js 实时渲染；交互图表（`.html`）则以 `<iframe>` 嵌入
4. **全文搜索**：背景异步加载所有 Markdown 文档内容创建索引，支持实时搜索主题名称、术语、以及文档全文
5. **路由**：使用 `hash` 路由（如 `#供应链管理`），支持浏览器上一页/下一页导览

**添加或修改主题时**，只需：
- 在 `src/` 对应文件夹内添加/编辑 Markdown 或 HTML 文档
- 在 `README.md` 中添加/更新该主题的链接列表（路径需包含 `src/` 前缀）
- `index.html` 会自动解析并呈现，无需额外设置

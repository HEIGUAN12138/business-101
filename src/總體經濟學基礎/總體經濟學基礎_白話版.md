# 总体经济学基础（白话版）

## 一、GDP：国家的总体成绩单

想像国家就像一个大公司，**GDP（国内生产毛额）** 就是这个「公司」每年赚的钱——所有人民生产出来的商品和服务加起来的总价值。你去餐厅吃饭、买手机、住饭店，这些支出都算进去。GDP有两种算法：名目GDP用现在的价格算，但通胀会影响数字；**实质GDP** 则消除掉通胀因素，才能看出经济是不是真的在成长。

如果去年GDP是100亿，今年是105亿，看起来成长5%，但如果发生通胀，实际购买力可能只成长2%。所以看新闻说「GDP成长2.5%」，要看的是实质成长，这样才能真实反映国家经济是不是变更好。简单说，**GDP越高代表经济活动越活跃，人民有更多任务作机会和收入**。

## 二、通货膨胀：为什么东西越来越贵？

去年50元的珍珠奶茶，今年涨到60元——这就是通胀。**通胀（Inflation）** 指所有东西的价格普遍上涨，你的薪水相对变得不值钱了。每个月政府会检查一篮子日常商品的价格，像食物、交通、房租，记录在 **CPI（消费者物价指数）** 里。

为什么会通胀？有三个原因：第一种是「需求太多」，大家都抢着买东西，卖家就涨价；第二种是「成本上升」，比如石油涨价，所有运输成本都跟着涨，东西自然更贵；第三种是「印太多钱」，政府乱印钞票，钱变薄，买东西需要更多钱。2021年开始全球通胀大爆发，美国物价一度涨了9%，大家买什么都感觉在挨刀子。

**内核通胀** 是把食物和油价这些波动大的项目拿掉，看本质通胀趋势。如果通胀超级严重，每个月价格涨50%以上，就叫**恶性通胀**，这时候钱几乎没有价值，像委内瑞拉那样，人民薪水根本追不上物价。

## 三、利率：借钱的价格

**利率** 就是借钱的利息率。你跟银行借100万买房，利率3%，一年要还3万利息。利率低的时候，借钱更便宜，企业更愿意投资，你也更想贷款买房；利率高的时候，借钱很贵，大家就会存钱而不是消费，经济成长就慢下来。

**央行（中央银行）** 就像经济的医生，用升息和降息来调理经济。降息刺激经济（打强心针），升息控制通胀（吃退烧药）。央行最常用的工具是「**公开市场操作**」，就是买卖债券，直接影响市场有多少钱在流动。2022年开始，美国央行不断升息，从几乎0%升到5.5%，目的是对付那9%的高通胀。

还有一招叫「**量化宽松（QE）**」，就是央行开心地印钱去买债券。2008年金融危机时用过，2020年疫情也用过。这做法很凶悍，能快速注入大量资金救急，但用过头也会推高通胀。

## 四、财政政策：政府如何花钱

政府像家长一样要管理预算：收入（税收）减去支出（公共服务、薪水、福利）。如果支出大于收入，产生**赤字**，就要借钱（发行国债）。借太多债最后问题很大，比如利息压力累积，最后可能还不出来。

政府花钱有个神奇效果叫「**乘数效应**」：政府支出1块钱，经过消费流动，最后可能变成5块钱的经济效益。因为政府给公务员发薪，公务员去消费，店家收入增加也去消费，钱会一直循环。但这个效果在经济已经很热、物价已经很高的时候会减弱。

**积极财政政策**（多花钱、少收税）在经济差的时候刺激；**紧缩财政政策**（少花钱、多收税）在经济过热时冷却。2020年疫情时各国都花超级多钱，现在又要收拾烂摊子。

## 五、景气循环：经济四季循环

经济就像四季一样循环：**春季（扩张）** 经济加速，企业招人投资，失业率下降，大家信心十足；**夏季（高峰）** 是最热的时候，增速开始放缓，泡沫风险出现；**秋季（衰退）** 经济开始缩小，企业裁员，大家失业增加；**冬季（谷底）** 最冷，接着又回到春季复苏。

衰退的正式定义是「**连续两季GDP下降**」。2020年疫情害的，美国GDP一下子掉31%（年化），超级恐怖，但复苏也很快，3个月后就开始回升。

经济学家看**领先指针**预测未来3-6个月会发生什么，比如股市表现、消费者信心；**同时指针**和现在经济同步，像失业率变化；**落后指针**则是已经发生的事，像银行坏帐。

## 六、汇率与国际贸易：钱的兑换率

你去日本旅游，台币能换多少日币？**汇率** 决定了这个。汇率受很多因素影响：如果美国升息，美元变值钱，美元升值；如果台湾通胀比美国高，台币就会贬值。

**货币升值**（台币变值钱）对旅游很爽，出去玩东西便宜；但对出口企业糟糕，因为国外要付更多钱才买得起你的东西，出口变难。**货币贬值**（台币变便宜）相反——出口多很好，但进口东西更贵，你买进口商品要花更多钱。

出口减进口叫**贸易顺差**，进口比出口多叫**贸易逆差**。美国常常贸易逆差，代表美国人爱买东西；德国常顺差，代表商品出口强。各国央行有时会「干预」汇市，买卖自己的货币来稳定汇率，这是很常见的经济政策。

## 七、失业率：有多少人没工作？

**失业** 分三种：**摩擦性失业** 就是换工作时的失业，正常现象；**结构性失业** 是产业转变导致，比如报纸没人要了，记者就难找工作；**循环性失业** 是经济衰退时，需求下降人们被裁员。

**失业率** 就是没工作的人占劳动力的比例。通常失业率太低（2-3%）代表劳动力紧张，老板没人可以招，会被迫加薪；失业率太高（6-8%以上）代表经济差，工作难找，薪水被压低。美国现在失业率约3.5%，算很低。

有个曲线叫**菲利普曲线**，描述一个现象：**失业率越低，通胀越容易上升**。因为人难招，老板要加薪抢人；人多了，工人有议价能力，薪水也会涨；薪水涨，东西就跟着涨价。所以央行要平衡：不能失业率太高（太多人没工作），也不能太低（通胀失控）。

## 八、供给派vs需求派：经济应该怎么救？

经济学家分两派。**凯因斯派** 认为经济差是因为人们不消费、不投资，所以政府要出手刺激需求，多花钱、减税，让大家敢买敢投资，带动整体景气。凯因斯派相信价格不会自动调整，市场会「卡住」，需要政府推一把。

**供给派** 认为反了，应该减税减管制，让企业更愿意生产和投资，供给多了自然价格就便宜，经济自动好转。他们觉得政府花太多钱只会推高通胀，不如信任市场的力量。

现实是两派都有道理。在经济大萧条时，凯因斯的方法确实有效；但在通胀爆涨时，供给派的减税刺激也有帮助。大多数国家现在混合用两种方法。

## 九、这些指针怎么影响你的人生？

如果你在考虑要不要买房、要不要创业、要不要投资，总体经济指针很重要。

**GDP快速成长** → 经济火热，工作多机会多，是创业或换工作的好时机

**通胀高企** → 东西越来越贵，房贷利息高，存钱变薄，要想办法增加收入追上物价

**央行升息** → 房贷、车贷利息都涨，买房成本上升，不是买房好时机；但存钱收益增加，适合资金停泊

**央行降息** → 贷款便宜，买房买车好时机，但存款利息超低，钱贬值快

**失业率上升** → 经济可能要衰退，先稳住工作别乱动，存钱做储备；企业要控制成本

**失业率下降** → 人才荒，员工跳槽容易，企业要加薪抢人；也是求职的好时机

**货币升值** → 进口便宜，出口难；旅游购物爽，国内制造业压力大

**货币贬值** → 出口好卖，进口变贵；国外旅游贵，但利于创意产业外销

聪明人会定期看GDP、CPI、失业率、利率这些数字，了解经济方向，提前为人生与事业做准备。

# 供应链管理：练习与自测

## 是非题（10题）

**题目 1**
供应链管理只涉及物流与仓储。

**答案**：否

**解析**：供应链管理涵盖原材料采购、生产、物流配送、销售预测、库存管理等多个环节，物流只是其中一部分。

---

**题目 2**
「及时制」（JIT）在所有情况下都能降低企业成本。

**答案**：否

**解析**：JIT在稳定、可预测的环境中有效，但在供应不确定、突发情况频繁的环境中会增加风险。2020年疫情期间许多企业因过度采用JIT而面临库存不足。

---

**题目 3**
长鞭效应的主要原因是消费者购买行为的波动。

**答案**：否

**解析**：长鞭效应的根本原因是信息延迟、订单批量化决策、价格波动诱导囤积等供应链设计问题，而非纯粹的消费者需求波动。

---

**题目 4**
供应商评估时，价格是唯一需要考虑的因素。

**答案**：否

**解析**：现代供应商评估应综合考虑质量、交付、创新、财务健康、环保责任等多维度，单纯以价格衡量会遗漏关键风险。

---

**题目 5**
ABC库存分类法中，C类商品应该保持最少的安全库存。

**答案**：否

**解析**：ABC分类中，C类商品（低价值、低频销售）应保持相对较高的安全库存，因为缺货的相对成本高；而A类商品应保持较低安全库存以降低持有成本。

---

**题目 6**
区块链技术可以完全解决供应链的透明性问题。

**答案**：否

**解析**：区块链只能确保已记录信息的真实性与不可篡改性，但无法确保最初信息的准确性（垃圾进垃圾出原则）。供应链透明性还需要依赖企业间的信任与信息共享意愿。

---

**题目 7**
推式（Push）供应链总是比拉式（Pull）供应链的成本更低。

**答案**：否

**解析**：推式供应链制造成本低但库存成本高；拉式供应链库存成本低但制造成本高。哪种更便宜取决于产品特性与市场环境。

---

**题目 8**
VMI（供应商管理库存）意味着供应商完全负责客户的库存决策。

**答案**：否

**解析**：VMI是一种协作模式，供应商根据约定的库存目标与客户共享的销售数据进行补货决策，但客户仍保持一定的监督与控制权。

---

**题目 9**
供应链的数字化只涉及采购与库存管理系统。

**答案**：否

**解析**：供应链数字化涵盖IoT传感、区块链追溯、AI预测、数字孪生、自动化等多个领域，影响从原材料到最后一哩配送的全过程。

---

**题目 10**
苏伊士运河搁浅事件证明全球供应链应该转向本地化生产。

**答案**：否

**解析**：该事件提醒我们应该进行地理多元化、创建备用运输方案、增加战略库存，而非完全放弃全球化。完全本地化会丧失全球化的效率优势。

## 选择题（10题）

**题目 1**
以下哪个不是供应链管理的核心目标？

A. 降低成本
B. 提高客户满意度
C. 增加市场占有率
D. 提升供应链韧性

**答案**：C

**解析**：增加市场占有率是企业战略目标，不是供应链管理的直接目标。供应链管理的核心目标是通过优化流程支撑企业目标。

A. 关键物料战略
B. 战略伙伴战略
C. 杠杆采购战略
D. 日常物料战略

**答案**：C

**解析**：高价值、低供应风险的商品可以通过集中采购、规模竞争、招标等方式降低成本。

**题目 3**
经济订购量（EOQ）公式中，订购频次增加时，年度总成本会如何变化？

A. 总是增加
B. 总是减少
C. 先增后减，存在最优点
D. 保持不变

**答案**：C

**解析**：订购频次增加会降低持有成本（更新周期短）但增加订购成本（次数多）。两者的平衡点就是EOQ。

**题目 4**
若产品需求标准差σ=50件/月，订购提前期L=10天，目标服务水准97.5%（Z=1.96），安全库存应该是多少？

A. 10件
B. 20件
C. 35件
D. 50件

**答案**：C

**解析**：
安全库存 = Z × σ × √L
σ(日) = 50/30 = 1.67件/日
安全库存 = 1.96 × 1.67 × √(10/30) = 1.96 × 1.67 × 0.577 ≈ 1.9 × 18.5 ≈ 35件

## 情境分析题（3-4题）

### 情境一：鲜花供应链危机

背景：一家花卉批发企业与全国100家花店合作，供应鲜花。

**情景**：疫情导致进口鲜花被禁，企业需要改为采购本地种植花卉。但本地花农分散在20个不同地区，供应不稳定，某些品种（进口玫瑰、郁金香）无本地替代品。

**问题 1**：企业应该采用什么库存策略应对本地供应的不稳定性？

**答案要点**：
- 增加安全库存（对易保存品种）
- 为缺乏替代品的品种创建战略库存
- 对于易腐烂品种，与花农签订更灵活的订购协议
- 考虑创建本地干花、永生花等保存时间长的替代品

**问题 2**：如何应用延迟策略来降低鲜花腐损？

**答案要点**：
- 采购鲜花后不立即配送到花店
- 存放在统一的冷链仓库
- 根据花店的实时订单，在最后48小时内进行分拣与配送
- 减少花店端的库存时间，降低腐损率

### 情境二：汽车零部件供应商的多元化困境

背景：一家汽车制造商向供应商甲采购关键零件（变速器），占全球产能的80%。为了应对风险，企业决定创建第二供应商乙。

**问题 1**：企业应该预留多少产能给第二供应商？

**答案要点**：
- 若完全替换：需要20-30%（供应商甲不愿意失去主订单，而且切换成本高）
- 实务做法：首先预留10-15%的订单给乙测试
- 6个月后根据乙的绩效逐步增加至20-25%
- 保持供应商甲的80%+以维持成本竞争力

**问题 2**：这个多元化战略的成本代价是什么？

**答案要点**：
- 制造成本增加：供应商乙的产能规模小，成本可能高10-20%
- 管理成本增加：需要维护两套质检、物流体系
- 沟通成本：协调两家供应商的交期、质量标准
- 预计年增成本：2000-5000万元（具体视订购规模）

### 情境三：电商配送的速度与成本权衡

背景：一家电商平台在华东地区与3家物流公司合作，目标是实现「48小时配送」。

**当前情况**：
- 物流成本：12元/件
- 配送速度：48-72小时
- 客户满意度：80%

**优化目标**：达成「24小时配送」

**问题**：实现24小时配送需要什么供应链改变？成本增加多少？

**答案要点**：

1. **仓储布局**：
   - 从3个区域仓库 → 添加8-10个小型分仓
   - 成本：年增1000-2000万元（仓租、人力、系统）

2. **库存预置**：
   - 将热销商品（占SKU的20%、销量的80%）提前分散存放
   - 资金占用增加：5000-1亿元

3. **运输优化**：
   - 专线配置：市区内24小时内快配人员
   - 与第4家快速物流商合作（成本更高，服务更快）
   - 物流成本增加：5-10元/件 → 新成本17-22元/件

4. **信息系统**：
   - 实时库存可见性、智能派单、路线优化
   - 系统投资：2000-3000万元

**成本总结**：
- 年增运营成本：5000-7000万元
- 在此基础上，客户满意度预计提升至90-95%
- 决策点：这5000-7000万的投资能带来多少额外销售与品牌溢价

## 计算题（3-4题）

### 计算题一：安全库存与服务水准

**题目**：
某快消品公司销售牙膏，年销量120,000件，日销量均匀，标准差50件/天。采购提前期为14天。

要求：
1. 计算不同服务水准下的安全库存
2. 如果仓储成本为1元/件/年，比较不同服务水准的库存成本代差

**已知**：
- Z(90%) = 1.28
- Z(95%) = 1.65
- Z(99%) = 2.33

**解答**：

公式：安全库存 = Z × σ × √L

其中 L = 14天，σ = 50件/天

1. **安全库存计算**：
```
90%服务水准：
SS₉₀ = 1.28 × 50 × √14 = 1.28 × 50 × 3.74 = 239件

95%服务水准：
SS₉₅ = 1.65 × 50 × √14 = 1.65 × 50 × 3.74 = 308件

99%服务水准：
SS₉₉ = 2.33 × 50 × √14 = 2.33 × 50 × 3.74 = 435件
```

2. **库存成本对比**：
```
90%：年持有成本 = 239 × 1元 = 239元
95%：年持有成本 = 308 × 1元 = 308元
99%：年持有成本 = 435 × 1元 = 435元

成本差异：
- 从90%→95%增加69元（9%的安全库存提升）
- 从95%→99%增加127元（14%的安全库存提升）
```

3. **决策建议**：
对于标准化、重复购买的日用品，95%的服务水准通常是最优选择，平衡缺货成本与库存成本。

### 计算题二：经济订购量（EOQ）

**题目**：
制造商每年采购100,000件零件。每次订购成本（处理、检验、物流）为500元。零件年度单位持有成本为20元/件。

要求：计算经济订购量与最优订购策略

**解答**：

公式：EOQ = √(2×D×S / H)

代入：D = 100,000，S = 500，H = 20

```
EOQ = √(2 × 100,000 × 500 / 20)
    = √(100,000,000 / 20)
    = √5,000,000
    = 2,236件
```

**最优订购策略**：
- 每次订购量：2,236件
- 年订购次数：100,000 ÷ 2,236 ≈ 45次
- 订购间隔：365 ÷ 45 ≈ 8天

**成本计算**：
```
年度订购成本 = (D/Q) × S = (100,000/2,236) × 500 = 22,359元
年度持有成本 = (Q/2) × H = (2,236/2) × 20 = 22,360元
总成本 = 22,359 + 22,360 = 44,719元
```

**对比非最优方案**：
```
若订购量为1,000件/次：
- 订购成本：(100,000/1,000) × 500 = 50,000元
- 持有成本：(1,000/2) × 20 = 10,000元
- 总成本：60,000元

若订购量为5,000件/次：
- 订购成本：(100,000/5,000) × 500 = 10,000元
- 持有成本：(5,000/2) × 20 = 50,000元
- 总成本：60,000元

结论：EOQ在2,236件时成本最低（44,719元），比其他方案节省约25%
```

### 计算题三：长鞭效应量化分析

**题目**：
零售商的月销售数据如下：
```
月份    实际销量
1月     1000件
2月     1050件
3月     950件
4月     1100件
5月     900件
```

但批发商根据订单情况，估计增长率为：
```
1月预估：+5% → 订货量1050件
2月预估：+5% → 订货量1103件
3月预估：-10% → 订货量993件
4月预估：+15% → 订货量1142件
5月预估：-20% → 订货量914件
```

要求：计算长鞭效应比例

**解答**：

1. **计算需求波动**：
```
实际销量波动 = (最高值 - 最低值) / 平均值 × 100%
平均销量 = (1000+1050+950+1100+900) / 5 = 1000件
波动范围 = 1100 - 900 = 200件
波动率 = 200 / 1000 = 20%
```

2. **计算订单波动**：
```
订货量波动 = (最高值 - 最低值) / 平均值 × 100%
平均订货 = (1050+1103+993+1142+914) / 5 = 1040.4件
波动范围 = 1142 - 914 = 228件
波动率 = 228 / 1040.4 = 21.9%
```

3. **长鞭效应比例**：
```
长鞭倍数 = 订单波动率 / 需求波动率 = 21.9% / 20% ≈ 1.1倍

说明：
- 实际销量波动20%
- 批发商订单波动21.9%（略高于实际）
- 倍数接近1，说明长鞭效应不明显

如果加入更多层级（制造商、供应商），波动会进一步放大：
- 制造商可能看到30%的波动
- 供应商可能看到50%以上的波动
```

## 延伸思考题（2-3题）

### 思考题一：供应链管理在ESG时代的新挑战

**题目**：
企业承诺在2030年实现「碳中和供应链」。但目前主要供应商位于成本低廉的发展中国家，这些地区：
- 能源仍以煤炭为主
- 环保法规宽松
- 转向绿色能源成本高达30-50%

**问题**：
1. 企业应该如何在成本竞争与ESG承诺之间平衡？
2. 如果不愿意承担绿色转型成本，企业会面临什么长期风险？

**延伸思考方向**：
- 与供应商共担绿色投资成本（降价幅度换换环保投资）
- 寻求替代供应商（成本上升但环保达标）
- 转向本地化采购（接近绿色能源发达的区域）
- 通过品牌溢价与消费者沟通，抵消成本上升
- 在供应链中寻找效率提升机会，用节省的成本抵销绿色投资

**评估标准**：
- 考虑了多方利益相关者（供应商、消费者、环境）
- 提出了现实可行方案，而非纯理想愿景
- 量化成本与收益的权衡

### 思考题二：地缘政治风险下的供应链战略

**题目**：
一家消费电子企业依赖台湾供应商供应80%的核心零件。随着地缘政治风险上升，企业考虑多元化供应源，但替代供应商有以下特点：

- **日本供应商**：成本高20%，质量等同，但政治风险更低
- **韩国供应商**：成本高15%，质量略低，需要3-6个月认证期
- **越南供应商**：成本高10%，质量需观察，规模小但发展潜力大
- **美国供应商**：成本高30%，质量优秀，获得政策支持

**问题**：
企业应该采用什么供应商多元化策略？考虑以下因素：
1. 长期成本
2. 风险承受能力
3. 技术发展前景
4. 政策与地缘政治变化

**延伸思考方向**：
- 产品线与供应源的对应（高利润产品用最安全的供应源）
- 时间推进（逐步过渡 vs 快速转移）
- 供应商扶持（帮助新供应商提高能力，长期节省成本）
- 技术替代（寻求不同技术路线，减少对特定供应商的依赖）

### 思考题三：最后一哩配送的优化困局

**题目**：
电商企业提供「24小时送达」服务，成本为15元/件。但客户投诉率高：
- 15%的单件被误送或遗失
- 配送人员服务态度差
- 投诉处理周期长

降低配送成本的方案A（众包配送，成本8元/件）会进一步恶化服务质量。

**问题**：
1. 企业应该如何在成本与服务质量之间做出决策？
2. 有没有「第三条路」——既降低成本又提升质量？

**延伸思考方向**：
- 差异化配送（不同客户不同方案）
- 技术赋能（无人配送、智能分拣）
- 客户预期管理（改变消费者对速度的预期）
- 模式创新（客户到驿站自取 vs 上门配送）
- 数据分析（找出高风险的配送环节与地点，针对优化）

**评估标准**：
- 真实理解消费者需求，而非盲目追求速度
- 提出可量化的成本-效益分析
- 考虑长期品牌价值，而非短期成本节省

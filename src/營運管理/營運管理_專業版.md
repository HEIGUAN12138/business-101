# 营运管理：专业版

## 一、营运管理的定义与范畴

营运管理（Operations Management）是一门致力于将组织的资源转换为产品与服务的学科。根据APICS（现为ASCM）的定义，营运管理涵盖所有计划、调度与控制物料、信息与资本流动的活动，以满足客户需求。

**内核职能领域包括：**
- **生产运营**（Manufacturing Operations）：制造业的制程管理
- **服务运营**（Service Operations）：医疗、零售、金融等服务业
- **供应链管理**（Supply Chain Management）：采购至交付的全流程
- **质量管理**（Quality Management）：持续改善与缺陷预防
- **存货控制**（Inventory Control）：库存优化与成本降低

营运管理的成功直接影响企业的成本结构、客户满意度与竞争优势。在当代全球经济中，有效的营运策略已成为企业策略性竞争力的关键。

## 二、流程设计与分析（Process Design & Analysis）

### 2.1 流程基本架构

流程（Process）是一系列有序的活动，将一个或多个投入转换为预期的产出。优秀的流程设计需要平衡三个维度：

| 维度 | 说明 | 范例 |
|------|------|------|
| **成本效率** | 最小化资源消耗 | 自动化制造、标准化服务 |
| **质量卓越** | 提高产出质量与一致性 | 六标准差、持续改善 |
| **时间敏捷** | 缩短运气时间，快速反应 | 精实生产、敏捷制造 |

### 2.2 流程映射与分析（Process Mapping）

流程映射（Process Mapping）是通过可视化方式记录流程的每一步。常用工具包括：

**价值流图分析（Value Stream Mapping, VSM）**：标识流程中的增值活动（VA）与非增值活动（NVA）。在制造业中，通常只有10-30%的时间用于增值活动，其余为等待、搬运等浪费。

**流程瓶颈分析**：识别限制流程效率的环节。根据Goldratt的制约理论（Theory of Constraints），每个系统都有一个瓶颈，管理着整体产出。

### 2.3 流程重新设计（Business Process Reengineering, BPR）

Hammer与Champy于1990年代提出的BPR强调根本性、剧烈性的流程改造。成功案例包括：

- **IBM信用部门**：从7天缩短至4小时的信用审批
- **Kodak图像处理**：通过自动化减少90%的处理人力

## 三、产能规划（Capacity Planning）

### 3.1 产能的定义与测量

产能（Capacity）是指单位时间内的最大产出量。根据利用率（Utilization Rate）的不同，产能有三种衡量方式：

1. **理论产能**（Design Capacity）：设备在最优条件下的产出量
2. **有效产能**（Effective Capacity）：考虑计划停机、保养后的产出量（通常为理论产能的80-90%）
3. **实际产能**（Actual Output）：考虑所有现实因素后的实际产出

**产能利用率公式：**
```
利用率(%) = 实际产能 / 有效产能 × 100%
效率(%) = 有效产能 / 理论产能 × 100%
```

### 3.2 产能规划策略

**追踪策略（Chase Strategy）**：调整产能以配合需求变化
- 优点：库存低、灵活性高
- 缺点：频繁调整成本高、员工波动大
- 适用：劳动密集、需求易预测的行业

**平衡策略（Level Strategy）**：保持稳定的产能
- 优点：员工稳定、成本可控
- 缺点：可能产生库存或无法满足需求
- 适用：产能难以快速调整的制造业

**混合策略（Hybrid Strategy）**：结合上述两种方法

### 3.3 长期产能决策

长期产能决策涉及重大资本投资，需要考虑：
- **需求预测**：用于估计未来产能需求
- **规模经济**：单位成本随产能增加而递减
- **技术选择**：不同技术的产能-成本曲线
- **风险评估**：需求不确定性对投资回报率的影响

## 四、存货管理（Inventory Management）

### 4.1 存货的功能与成本

存货（Inventory）在供应链中扮演缓冲角色，但同时产生成本。

**存货功能：**
1. **周期库存**（Cycle Stock）：满足常规需求
2. **安全库存**（Safety Stock）：应对需求波动与供应不确定性
3. **季节库存**（Seasonal Stock）：预见季节性需求变化
4. **交运库存**（Pipeline Inventory）：在供应链各环节的在途库存

**存货成本结构：**
- 购买成本（Product Cost）
- 持有成本（Holding Cost）：资金占用、仓储、过期损耗，通常为商品成本的20-40%
- 订购成本（Ordering Cost）：下单、运输、验收
- 缺货成本（Shortage Cost）：失去销售、客户流失、补救成本

### 4.2 经济订购量模型（Economic Order Quantity, EOQ）

EOQ是经典的库存优化模型，用于确定最优订购量。

**基本EOQ公式：**
```
EOQ = √(2DS/H)

其中：
D = 年度需求量
S = 每次订购成本
H = 年度单位持有成本
```

**范例计算：**
假设某零件年需求量为12,000件，每次订购成本$50，年度持有成本为$2/件

EOQ = √(2 × 12,000 × 50 / 2) = √600,000 ≈ 775件

**重要指针：**
- 订购次数（Order per year）= D / EOQ
- 平均库存（Average Inventory）= EOQ / 2
- 总相关成本（Total Relevant Cost）= (D/EOQ) × S + (EOQ/2) × H

### 4.3 高级库存模型

**考虑数量折扣的EOQ：** 当供应商提供大宗购买折扣时，需要评估折扣带来的成本节省是否超过额外的持有成本。

**周期性需求与时变需求：** 使用动态规划或启发式方法（如最低成本法）来处理非均匀需求模式。

**安全库存的确定：**
```
安全库存 = Z × σ × √LT

其中：
Z = 期望服务水准的标准分数（如99%对应Z≈2.33）
σ = 需求的标准差
LT = 前置时间（天数）
```

### 4.4 准时制（Just-In-Time, JIT）

JIT是一种极端的库存最小化策略，由Toyota开创。

**内核原则：**
1. **零缺陷**：质量问题必须在源头消除，不能依赖检验
2. **小批量生产**：减少一次性缺陷的影响
3. **频繁交付**：供应商与生产线之间的紧密协调
4. **前置时间最小化**：精简流程、标准化、自动化

**实施条件：**
- 稳定且可预测的需求
- 高度可靠的供应商
- 员工的多功能性与高技能
- 信息系统的完整集成

**成功案例：** Toyota能够将生产线库存保持在2-3小时产量，相较业界的2-3周产量优势明显。

## 五、精实生产（Lean Manufacturing）

### 5.1 精实生产的起源与演进

精实生产源于Toyota生产系统（Toyota Production System, TPS），在2000年代因Womack等人的著作在全球制造业推广。精实生产不仅是库存管理方法，而是一套完整的经营哲学。

### 5.2 七大浪费（Seven Wastes）

精实生产识别并消除七种浪费：

| 浪费类型 | 定义 | 范例 |
|---------|------|------|
| **过度生产** | 生产超过立即需求 | 批量过大、预测不准 |
| **等待** | 工作人员或物料的闲置 | 机器故障、排队等候 |
| **非必要搬运** | 物料无必要的移动 | 布局不合理、仓储地点远 |
| **加工浪费** | 不必要的制程步骤 | 过度检验、重复设置 |
| **库存** | 过量的在制品与成品 | 前置时间长、需求波动 |
| **动作浪费** | 不必要的人工动作 | 人体工程学设计不佳 |
| **缺陷与返工** | 质量问题导致返工 | 制程控制不佳 |

### 5.3 Toyota生产系统的两大支柱

**第一支柱：自动化（Jidoka）**
- 赋予机器与员工「停止异常」的权力
- 实施质量控制在制程内而非事后检验
- 员工可在发现问题时立即停止生产线

**第二支柱：JIT**
- 如前所述的准时制原则
- 与需求同步的拉式系统（Pull System）

### 5.4 拉式系统与看板（Kanban）

看板是实施JIT的核心控制机制。看板卡片（通常为实物或电子标签）流过生产系统，指示何时生产、运输或供应物料。

**看板运作逻辑：**
```
生产看板：通知上游工序何时生产
提取看板：指定物料供应商何时运输
```

**计算看板卡片数量：**
```
看板卡片数 = [日需求量 × (制造提前期 + 提取提前期)] / 容器容量 + 安全系数

典型安全系数：10-15%
```

### 5.5 精实实施方法：价值流图改善

改善过程通常分为五个步骤：

1. **识别价值**：从客户视角定义何为增值
2. **价值流映射**：绘制现状与未来状态图
3. **创建流动**：消除批量生产，实现单件流（Single Piece Flow）
4. **实施拉式系统**：从推式改为拉式生产
5. **持续改善**：创建Kaizen（改善）文化

## 六、六标准差（Six Sigma）

### 6.1 六标准差的统计基础

六标准差是一套系统的质量改善方法，目标是将制程变异控制在极低水准。「六标准差」指制程平均值距规格上下限各6个标准差，不良率为3.4百万分之一（DPMO）。

**对比三标准差：**
- 三标准差：不良率0.27%（每万件有27件不良）
- 六标准差：不良率0.00034%（每百万件有3.4件不良）

### 6.2 DMAIC改善循环

六标准差的核心方法是DMAIC，由五个阶段组成：

#### **D - 定义（Define）**
- 识别改善项目与客户关键需求
- 定义现状绩效指针（Baseline Metrics）
- 估计改善的财务影响

#### **M - 测量（Measure）**
- 选择关键性能指针（KPI）
- 进行制程能力分析（Cpk分析）
- 评估测量系统的有效性（MSA - Gage R&R）

**制程能力指数（Cpk）计算：**
```
Cpk = min[(USL - μ)/(3σ), (μ - LSL)/(3σ)]

其中：
USL/LSL = 上/下规格限
μ = 制程平均值
σ = 制程标准差

Cpk ≥ 1.67 对应六标准差水准
```

#### **A - 分析（Analyze）**
- 使用统计工具识别根本原因
- 常用工具：鱼骨图、假设检定、相关分析
- 确定关键X因素（改善的自变量）

#### **I - 改善（Improve）**
- 设计改善方案与试验
- 使用设计实验法（Design of Experiments, DOE）优化参数
- 试点测试与验证

**DOE范例：** 假设要改善注塑成型的尺寸精度，可测试温度（300°C、320°C、340°C）与压力（80Bar、100Bar、120Bar）的9种组合，找到最优参数组合。

#### **C - 控制（Control）**
- 创建标准化流程与控制图
- 培训员工并持续监控
- 防止改善成果的反弹

### 6.3 六标准差的认证与角色

- **黑带（Black Belt）**：领导主要改善项目，年可贡献百万级美元收益
- **绿带（Green Belt）**：参与黑带项目或领导小规模改善
- **黄带（Yellow Belt）**：具备基本六标准差知识的员工

### 6.4 精实六标准差（Lean Six Sigma）

结合精实生产的速度与六标准差的精确性，形成更强大的改善方法。精实侧重流程速度与去除浪费，六标准差侧重质量与变异控制。

## 七、全面质量管理（Total Quality Management, TQM）

### 7.1 TQM的演进与定义

TQM是一种涵盖整个组织的经营哲学，强调质量不是质量部门的职责，而是每个员工的责任。

**关键特征：**
- 客户导向（Customer Focus）
- 过程导向（Process Orientation）
- 员工赋权（Employee Empowerment）
- 持续改善（Continuous Improvement）
- 数据驱动决策（Fact-Based Decision Making）

### 7.2 质量管理工具与方法

**统计过程控制（Statistical Process Control, SPC）**：
- 使用控制图（Control Charts）监控制程
- X-R图用于连续数据，P图用于不良率
- 当样本点超出控制限或出现异常趋势时，视为制程失控

**根本原因分析（Root Cause Analysis）**：
- 五个为什么法（5 Whys）：逐层问「为什么」以找到根本原因
- 鱼骨图（Fishbone Diagram）：系统地枚举所有可能原因
- 故障树分析（Fault Tree Analysis）：从失败结果反向追溯

### 7.3 ISO质量管理标准

**ISO 9001**：质量管理体系国际标准，涵盖：
- 领导层承诺与客户焦点
- 方针与目标的制定与沟通
- 资源与能力管理
- 运作规划与控制
- 绩效评估与改善

## 八、供应链营运与销售与营运规划（S&OP）

### 8.1 供应链营运的目标

供应链（Supply Chain）从原材料采购到最终客户交付的全过程。有效的供应链营运追求：

1. **成本最小化**：优化采购、运输、存货
2. **服务水准最大化**：高可用性、短交期、准确性
3. **敏捷性与灵活性**：快速应对市场变化
4. **可持续性**：环保与道德责任

### 8.2 采购决策

**自制vs外包决策分析：**
```
自制成本 = 固定成本 + (变动成本 × 年需求量)
外包成本 = 单位采购成本 × 年需求量

选择成本更低的方案，并考虑质量、风险、战略重要性
```

**供应商选择与管理：**
- 多源采购：分散风险但增加复杂性
- 单一源采购：成本优势但缺乏冗余
- 分类采购：根据物料的策略重要性与供应风险进行四象限分类

### 8.3 销售与营运规划（Sales and Operations Planning, S&OP）

S&OP是一套集成销售预测、生产计划与库存管理的高层管理流程。

**S&OP流程的五个步骤：**

1. **需求规划**（Demand Planning）
   - 收集销售、市场与历史数据
   - 生成初步需求预测

2. **供应规划**（Supply Planning）
   - 评估现有产能与库存
   - 确定生产、采购与库存计划

3. **中间认可**（Pre-S&OP Meeting）
   - 财务部门审视成本影响
   - 初步协调各职能部门

4. **高层决策**（Executive S&OP Meeting）
   - 副总裁级别决策者参与
   - 平衡成长、利润与现金流
   - 做出资源配置决策

5. **运行与监控**（Execute and Monitor）
   - 将计划转化为具体指令
   - 追踪绩效并定期审视

**S&OP的财务影响：**
根据APICS统计，实施有效S&OP的企业通常能够：
- 存货减少10-15%
- 预测准确度提升10-15%
- 交期准确度达95%以上
- 利润增加2-3%

## 九、服务营运管理

### 9.1 服务营运的特性

服务营运不同于制造，具有独特特征：

| 特征 | 制造业 | 服务业 |
|------|--------|--------|
| **有形性** | 有形产品 | 多数无形 |
| **保存性** | 可库存 | 不可库存（容量浪费） |
| **客户参与** | 低 | 高 |
| **质量衡量** | 客观标准 | 主观感受 |
| **流程可变性** | 低 | 高 |

### 9.2 服务设计与传递

**服务蓝图（Service Blueprint）**：
类似于制造的流程图，但更强调客户接触点（Touchpoint）。蓝图包括：
- 客户行动线
- 前台员工行动线
- 后台支持流程
- 支持系统与资源

**范例：餐厅服务**
```
客户行动：进入→点餐→等待→用餐→结帐→离开
前台行动：迎接→记录→确认厨房→上菜→核对→收款
后台流程：采购→存货→厨房制备→品检→清洁
```

### 9.3 服务水准与产能管理

**座位预约率**（Booking Percentage）：容量预先销售的比例
- 航空业：常见95-98%
- 饭店业：常见85-90%

**排队理论（Queuing Theory）**：
```
L = λ / (μ - λ)  [M/M/1队列公式]

其中：
λ = 到达率（客人/时间）
μ = 服务率（客人/时间）
L = 平均队列长度
```

当λ接近μ时，队列快速增长，体验恶化。服务营运必须维持充足产能。

### 9.4 服务质量的衡量：SERVQUAL

SERVQUAL模型通过五个维度评估服务质量：

1. **有形性（Tangibles）**：设施、设备、员工外表
2. **可靠性（Reliability）**：准时交付、承诺兑现
3. **反应性（Responsiveness）**：员工的帮助意愿与速度
4. **保证性（Assurance）**：员工知识与礼仪
5. **同理心（Empathy）**：个人化关注与理解

## 十、调度与瓶颈管理（Scheduling & Theory of Constraints）

### 10.1 生产调度的目标与限制

生产调度（Production Scheduling）涉及分配工作、机器与员工以完成制造计划。目标通常包括：

- **最小化制期时间（Makespan）**：完成所有工作的总时间
- **最小化逾期交货**：确保按期交付
- **最小化设置时间**：减少机器调换品种的停机
- **机器利用率最大化**：提高产能使用效率

### 10.2 调度规则与算法

**优先规则（Dispatching Rules）**：

| 规则 | 逻辑 | 适用情况 |
|------|------|---------|
| **FCFS** | 先进先出 | 公平性优先 |
| **SPT** | 最短加工时间优先 | 最小化完成时间 |
| **EDD** | 最早交期优先 | 最小化逾期 |
| **CR** | 关键比率（(交期-今日)/(剩余工作时间)) | 平衡效率与准时 |

**案例：五项工作在单一机器上的调度**

| 工作 | 加工时间 | 交期 |
|------|---------|------|
| A | 3天 | 第8天 |
| B | 5天 | 第15天 |
| C | 2天 | 第5天 |
| D | 4天 | 第12天 |
| E | 1天 | 第6天 |

使用SPT规则的顺序：E(1) → C(2) → A(3) → D(4) → B(5)
- 制期时间：15天
- 平均完成时间：(1+3+6+10+15)/5 = 7天

### 10.3 Goldratt的制约理论（Theory of Constraints, TOC）

TOC是由Eliyahu Goldratt提出的管理方法论，强调系统中的瓶颈决定了整体产出。

**内核概念：**

1. **瓶颈的识别**：
   - 瓶颈（Constraint）：产能小于需求的资源
   - 非瓶颈（Non-Constraint）：有闲置产能的资源

2. **五聚焦步骤（Five Focusing Steps）**：

   **第一步：识别瓶颈**
   - 监控每个工作中心的利用率
   - 瓶颈的特点：总是繁忙、有待机工作积累

   **第二步：决定如何利用瓶颈**
   - 排除瓶颈内部的浪费与低效
   - 最大化瓶颈的有效产出时间
   - 优先生产高边际贡献的产品

   **第三步：使其他资源服从瓶颈**
   - 非瓶颈的产能应受瓶颈约束
   - 上游节点只生产足以供应瓶颈的数量
   - 避免瓶颈前产生堆积

   **第四步：解除瓶颈的限制**
   - 增加瓶颈的产能（购置设备、增加班次、外包）
   - 改进瓶颈的工艺流程

   **第五步：回到第一步**
   - 解除原瓶颈后，新的瓶颈将浮现
   - 持续迭代改善

### 10.4 鼓-缓冲-绳（Drum-Buffer-Rope, DBR）调度系统

DBR是TOC在实务中的实施工具：

- **鼓（Drum）**：瓶颈工作中心，决定整个系统的节奏
- **缓冲（Buffer）**：在瓶颈前设置时间或库存缓冲，防止瓶颈饿食
- **绳（Rope）**：一套同步机制，确保上游工作进度与瓶颈同步

**DBR的优势：**
- 大幅减少在制品库存
- 提高交期准确度
- 最小化瓶颈的等待时间

## 十一、营运管理在现代企业中的应用

### 11.1 智能制造与工业4.0

数字化技术正在革新营运管理：

**物联网（IoT）与感知器**：实时监控设备状态、产线绩效、库存位置
**大数据分析**：预测维护、需求预测、异常侦测
**云计算**：实现全球供应链的可视化与协调
**人工智能**：自动化决策、机器学习优化调度

### 11.2 可持续与绿色营运

- **减少废弃物**：精实生产与循环经济原则
- **能源效率**：优化生产工艺、使用可再生能源
- **责任采购**：评估供应商的环保与劳工标准

### 11.3 敏捷供应链

在疫情与地缘政治风险下，企业需要：
- 多元化供应商与制造地点
- 快速响应市场变化的灵活流程
- 与供应商的深度合作与信息共享

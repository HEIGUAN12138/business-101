> 本练习涵盖本主题的核心概念，包括是非题、选择题、名词配对、情境分析与计算应用。建议先自行作答，再参考答案解析进行检讨。

## 一、概念快速检测（是非题）

### 题目

1. **生产力（Productivity）是指单位时间内的产出量，与产能（Capacity）没有区别。**

2. **经济订购量（EOQ）模型假设需求是恒定且可预测的，这个模型在需求不稳定时无法使用。**

3. **精实生产（Lean Manufacturing）的目标是完全消除库存，达到零库存状态。**

4. **六标准差（Six Sigma）方法中，DMAIC循环的「控制」阶段是最后一步，完成后不需要再回到「定义」阶段。**

5. **Just-In-Time（JIT）系统要求供应商频繁小量交货，这会增加供应商的成本，但对制造企业有利。**

6. **服务营运与制造营运的根本区别是服务无法库存，因此必须100%准确预测需求。**

7. **制约理论（Theory of Constraints）认为系统的整体绩效受限于最弱的环节（瓶颈）。**

8. **统计过程控制（SPC）是一种事后检验方法，用来检查已完成的产品是否符合标准。**

9. **销售与营运规划（S&OP）主要是销售部门的职责，生产部门只需运行计划。**

10. **供应链设计中，采用多个供应商会增加企业的谈判成本，因此单一供应商是最优选择。**

### 答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | **X 错误** | 产能（Capacity）是理论上的最大产出量；生产力（Productivity）是实际达到的产出量或产出与投入的比率。两者不同。 |
| 2 | **O 正确** | EOQ假设需求稳定，当需求波动大时，需要用更复杂的动态规划或启发式方法。 |
| 3 | **X 错误** | 精实生产目标是消除浪费，而非完全零库存。安全库存和周期库存仍然是必要的，但应最小化。 |
| 4 | **X 错误** | 六标准差DMAIC是循环流程，「控制」阶段之后还应持续监控，当发现新问题时会再回到「定义」阶段，打开新一轮改善。 |
| 5 | **O 正确** | JIT要求频繁小量交货，增加了供应商的运输与协调成本。但通过长期合作与信息共享，整个供应链的整体成本反而降低。 |
| 6 | **X 错误** | 虽然服务无法库存，但通过容量预订、排队管理等手段，可以部分平衡供需，不需要100%精确预测。 |
| 7 | **O 正确** | 这是TOC的核心原理。系统输出受限于最弱环节的产能，改善其他部分不会提升整体绩效。 |
| 8 | **X 错误** | SPC是过程控制方法，应用在制程中监控，及时发现异常，属于预防性质而非事后检验。 |
| 9 | **X 错误** | S&OP是跨职能的高层管理流程，需要销售、生产、财务等部门协同决策，不是单方面职责。 |
| 10 | **X 错误** | 多供应商有风险分散、竞争压力、创新来源的优势，应根据物料重要性选择。单一供应商在某些情况下有效率优势，但缺乏冗余性。 |

### 答案

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | **D** | 利用率 = 实际产能 / 有效产能 = 800/850 ≈ 94%；效率 = 有效产能 / 理论产能 = 850/1000 = 85%。|
| 2 | **A** | EOQ = √(2 × 20000 × 100 / 5) = √(800000) ≈ 283件 |
| 3 | **D** | JIT的前提是稳定需求，正是因为不需要大的安全库存。大安全库存反而是JIT要消除的。 |
| 4 | **C** | A - 分析阶段是使用统计工具（如假设检定、相关分析）识别根本原因的阶段。 |
| 5 | **B** | 非瓶颈应受瓶颈约束，避免产生浪费的库存堆积，同时确保瓶颈有足够的投入。 |
| 6 | **B** | 垂直集成和地理靠近是Zara快速的关键。供应商靠近意味着短前置时间，能快速回应。 |
| 7 | **C** | 在M/M/1队列中，必须λ < μ才能达到稳定状态。若λ ≥ μ，队列会无限增长。 |
| 8 | **B** | TQM强调质量不是质量部门的事，而是全员参与的文化。 |
| 9 | **C** | 不做任何调整让缺货发生是不负责任的。正确做法应该是A、B、D之一或组合。 |
| 10 | **B** | SPC应该在制程进行中持续监控，及时发现异常，属于预防而非事后。 |

## 四、情境分析题

### 情境一：快速成长公司的产能困境

**背景：**
某科技公司生产软件授权，过去三年年成长率50%。今年销售预测为200万套，但目前客服团队只能处理100万套的安装、培训和支持。客服团队说需要1年时间才能招聘和培训新员工到熟手水准。

**问题：**
1. 这是什么性质的瓶颈？（短期vs长期，结构性vs非结构性）
2. 根据制约理论的五聚焦步骤，应该如何处理？
3. 可能的短期方案有哪些？

**参考答案：**

1. **瓶颈性质：**
   - 结构性瓶颈（不是暂时的，是系统设计的问题）
   - 长期瓶颈（需要1年才能解除）
   - 人力资源瓶颈（员工培训时间长）

2. **五聚焦步骤应用：**
   - 第一步：确认客服是瓶颈 ✓（已识别）
   - 第二步：最大化现有客服的效率
     - 优化服务流程，减少单个客户所需时间
     - 创建自助服务平台
     - 优先服务高价值客户
   - 第三步：使其他部门服从瓶颈
     - 销售部门调整销售节奏，不要短期内签太多大合约
     - 开发部门配合客服的负载
   - 第四步：突破瓶颈
     - 加快员工招聘（可能需要提高薪资）
     - 外包部分客服工作
     - 外聘顾问加快培训
   - 第五步：回到第一步
     - 解除客服瓶颈后，可能开发或销售变成新瓶颈

3. **短期方案（3-6个月）：**
   - 流程优化：标准化常见问题解答，减少处理时间20-30%
   - 自动化：创建聊天机器人处理常见问题
   - 外包：外包非核心支持工作
   - 灵活用工：聘请兼职或临时员工加班处理高峰期

### 情境二：供应商质量问题

**背景：**
某汽车零件制造厂，80%的零件由一家供应商提供。最近该供应商因产能满载，开始外包一部分订单给第二家厂商。结果交货的零件不良率从1%飙升至8%，导致组装线停工，客户开始投诉。

**问题：**
1. 这个情况违反了供应链管理的哪些原则？
2. 应该采用什么样的供应商策略来防止这类问题？
3. 短期和长期的解决方案是什么？

**参考答案：**

1. **违反的原则：**
   - 单一供应商的风险：没有冗余性，供应商的问题直接影响整个制造厂
   - 供应商能力评估不足：没有预留产能安全系数
   - 信息沟通不足：供应商应该提前通知要外包，制造厂应该评估资格

2. **改进的供应商策略：**
   - 多供应商策略：维持2-3家合格供应商，分散80%的订单为：
     - 主供应商：60%
     - 次供应商：30%
     - 备用供应商：10%
   - 供应商认证：对所有供应商（包括二级供应商）进行质量认证
   - 长期合作协议：明确说明不允许未授权外包

3. **解决方案：**
   - **短期（1-2个月）：**
     - 与现有供应商密集沟通，立即停止第三方外包
     - 增加检验抽样，确保进厂零件质量
     - 调整组装线进度，消化缺陷零件

   - **长期（3-12个月）：**
     - 开发第二家供应商，完成认证和小批量测试
     - 逐步转移30%订单到新供应商
     - 与主供应商协商增加产能投资（购置新设备、聘用员工）
     - 实施供应商质量改善计划（六标准差或Kaizen）

## 五、计算与应用题

### 问题一：安全库存计算

**题目：**
某医疗器材公司销售一种医疗设备。根据过去12个月的历史数据：
- 月均需求：1000台
- 需求标准差：150台
- 供应商前置时间：2个月
- 目标服务水准：95%（Z值为1.645）

请计算：
1. 安全库存（Safety Stock）
2. 再订购点（Reorder Point）
3. 若要将服务水准提升至99%（Z值为2.326），安全库存将增加多少？

**解答：**

**安全库存公式：**
```
SS = Z × σ × √LT

其中：
Z = 服务水准对应的标准正态分数
σ = 需求的标准差（月）
LT = 前置时间（月）
```

1. **95%服务水准的安全库存：**
```
SS = 1.645 × 150 × √2
   = 1.645 × 150 × 1.414
   = 349台（约）
```

2. **再订购点：**
```
ROP = 月均需求 × 前置时间 + 安全库存
    = 1000 × 2 + 349
    = 2,349台

解释：当库存降至2,349台时，应该下单，这样在供应商2个月内送达时，
库存恰好降至349台的安全库存
```

3. **99%服务水准的安全库存：**
```
SS99% = 2.326 × 150 × √2
      = 2.326 × 150 × 1.414
      = 494台

增加量 = 494 - 349 = 145台（约41%增加）
```

**管理意涵：**
- 服务水准提升4%（从95%到99%），需要增加145台库存
- 企业需在质量保证和库存成本间权衡
- 对于生命攸关的医疗设备，99%甚至99.9%的服务水准可能是合理的

### 问题二：制约理论应用

**题目：**
某家具制造厂有三个主要工作中心：
- 切割中心（Cutting）：产能60件/天
- 组装中心（Assembly）：产能50件/天
- 油漆中心（Painting）：产能55件/天

目前订单充足，每天应接订单100件（每件都要经过三个工序）。

问题：
1. 哪个工作中心是瓶颈？
2. 目前的实际产出是多少？
3. 根据TOC，应该如何处理非瓶颈工作中心？
4. 解除瓶颈的投资是什么？

**解答：**

1. **识别瓶颈：**
   - 切割：产能60件/天 > 需求100件/天？不够
   - 组装：产能50件/天 < 需求100件/天 ← **瓶颈**
   - 油漆：产能55件/天 > 需求100件/天？接近瓶颈

**组装中心是瓶颈**，因为产能最低。

2. **实际产出：**
```
实际产出 = 瓶颈的产能 = 50件/天

即使订单有100件，也只能生产50件。
利用率：
- 切割中心：50/60 = 83%（有闲置产能）
- 组装中心：50/50 = 100%（满载）
- 油漆中心：50/55 = 91%（有闲置产能）
```

3. **非瓶颈的处理：**
   - 切割中心只应生产50件/天（供应组装需求），不要为了提高自身利用率而超额生产
   - 油漆中心只应生产50件/天（满足组装的输出）
   - 三个中心应同步运作，避免组装前产生库存堆积

4. **突破瓶颈的方案：**

若要日产100件，需要提升组装中心的产能。投资选项：

| 方案 | 成本 | 时间 | 效果 |
|------|------|------|------|
| 增加班次（加班） | $2000/天 | 立即 | 可增至60-70件/天 |
| 购置新组装机器 | $200,000 | 3个月 | 可增至80-100件/天 |
| 简化组装流程（改善） | $50,000 | 2个月 | 可增至60-70件/天 |
| 外包部分组装 | 变动成本$500/件 | 2-4周 | 可增至80-100件/天 |

**最优选择：** 先用加班和流程改善达到70-75件/天（成本$52,000，时间2个月），再评估是否购置新设备达成100件/天。

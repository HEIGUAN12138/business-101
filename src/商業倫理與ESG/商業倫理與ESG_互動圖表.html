社会（S）

治理（G）

企业内部控制与廉正管理

董事会结构: 独立董事比例、多元性、专业背景、任期制度
高管薪酬: CEO与员工薪酬比、绩效挂钩、长期激励
反贪腐与合规: 反贿赂政策、廉政训练、内部举报机制、监管记录
信息透明: 财务披露完整性、ESG报告、关联交易披露、风险管理
利害关系人矩阵帮助企业识别各利害关系人的影响力与利益关系，制定相应的沟通与管理策略。

企业应如何与不同利害关系人交互？

▲ 高影响力 + 高利益关系

策略：密切管理、定期沟通

  • 股东：定期投资者会议、年报披露
  • 主要客户：定制化服务、回馈机制
  • 主要供应商：策略伙伴关系、共同发展
  • 员工：参与决策、发展计划

▲ 高影响力 + 低利益关系

策略：监测与回应

  • 政府监管机构：合规、定期报告
  • 媒体：透明沟通、危机管理
  • 环保与人权NGO：对话与合作
  • 业界协会：标准设置参与

▼ 低影响力 + 高利益关系

策略：保持满意、适度参与

  • 小供应商：公平对待、付款按时
  • 员工家庭：员工福利计划、工作-生活平衡
  • 内部社区：当地就业、环保承诺
  • 广义消费者：产品质量、客服

▼ 低影响力 + 低利益关系

策略：定期监控

  • 远距社区：定期回馈、必要时参与
  • 一般大众：公开信息、品牌形象维护
  • 未来世代：永续政策、长期承诺
  • 学术机构：研究合作、数据分享

ESG投资策略比较展示不同的永续投资方法，各有优缺点与适用场景。
投资策略 基本原理 风险水准 预期回报 社会影响
排除筛选法 排除有害产业（烟草、武器、化石燃料等） 低 中等 高
最佳选择法 在各产业中选择ESG表现最好的企业 低 高 中等
正面筛选法 主动投资永续发展与绿色科技企业 中等 高 高
企业参与法 与企业对话推动ESG改善，甚至投票施压 中等 中等 高
影响力投资 投资于可测量社会/环境正面影响的企业 高 中等 高
ESG集成 在传统财务分析中纳入ESG因素 低 高 中等

选择策略的考虑因素：

  • ✓ 风险承受度：保守投资者倾向排除筛选法，积极投资者可选择影响力投资
  • ✓ 社会承诺：若重视社会影响，正面筛选法与影响力投资更合适
  • ✓ 投资规模：大型机构投资者可进行企业参与，小型投资者适合基金方式
  • ✓ 时间承诺：影响力投资需要更长期的耐心，短期回报可选择最佳选择法

🦋 循环经济 = 生物循环 + 技术循环

左翅（生物循环）：可生物降解的材料回归土壤
右翅（技术循环）：金属、塑料等无限回收利用

🌱 生物循环（左翅）

材料: 棉、羊毛、纸、树木、生物塑料等

设计原则:

  • 100% 可生物降解
  • 避免有害化学物质
  • 回归土壤成为养分

案例: Patagonia有机棉衣物可堆肥、Allbirds羊毛运动鞋

♻️ 技术循环（右翅）

材料: 金属、玻璃、高质量塑料等

设计原则:

  • 易于拆卸分类
  • 无限次回收利用
  • 零废弃物目标

案例: Fairphone模块化手机、Interface地毯回收计划

永续商业模式比较

商业模式 概念 环保效益 企业动力
产品即服务（PaaS） 企业保有所有权，消费者租服务 企业激励制造耐用、易维修产品 保留产品可回收利用
共享经济 多个用户共享单一产品 减少制造业规模 提高单个产品利用率
再制造 回收旧产品，更新零件后重卖 节省70-80%制造能源 成本低于新制造30-50%
逆物流回收 创建系统回收使用过的产品与包装 转化废弃物为新资源 取代昂贵的原料采购

⚠️ 漂绿与真实循环的区别

❌ 漂绿案例

  • 宣称「回收计划」但回收率低于5%
  • 购买碳抵消声称「碳中和」但自身未减碳
  • 纸质包装外层但内层仍是塑料
  • 自编ESG报告，无第三方验证

✓ 真实循环

  • 详细披露回收率与目标进度
  • 优先进行实质减碳，抵消仅补不足
  • 整个生命周期设计易于循环
  • 第三方认证（Cradle to Cradle等）

企业ESG发展的五个阶段

第一阶段

初期（Ad Hoc）

ESG未被系统化管理，主要应对监管或危机。
无正式ESG策略
反应式管理风险
有限的数据与报告
缺乏跨部门协调
第二阶段

发展中（Developing）

开始创建基础流程与治理，但运行仍不完整。
制定ESG政策
创建责任部门
开始定期报告
部分供应链审计
第三阶段

成熟（Mature）

ESG集成入业务策略与决策，有明确目标与绩效跟踪。
ESG与商业战略链接
定量目标与KPI
高管薪酬与ESG挂钩
完整供应链管理
第四阶段

优秀（Advanced）

ESG已成为内核文化，创造共享价值与创新。
ESG驱动创新与新业务
行业领导与倡导
第三方认证与验证
透明与集成报告
第五阶段

卓越（Exemplary）

ESG已成为企业存在的目的，引领行业与社会转型。
目的驱动企业（Purpose-Driven）
系统性解决全球挑战
完全透明与问责
利害关系人资本主义践行

从成熟迈向优秀的关键行动：

  1. 将ESG与创新挂钩，寻找新的商业机遇
  2. 进行第三方认证与独立审计，创建信誉
  3. 与业界同侪合作推动标准与变革
  4. 增强供应链的能力建构而非简单的审计
  5. 创建透明的利害关系人对话机制
